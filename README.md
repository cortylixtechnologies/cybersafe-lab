# CyberSafe Lab

Create a modern, professional, responsive Cybersecurity Awareness Training Website called "CyberSafe Awareness Lab".

Purpose: Educate non-technical users about cybersecurity through safe interactive simulations. This website is for awareness and training only. No real credential collection, attacks, malware, password cracking, or offensive functionality should exist. All demonstrations must be educational simulations.

Design Requirements

Modern cybersecurity theme

Dark mode with blue neon accents

Responsive for desktop and mobile

Professional animations

Progress tracker

Interactive dashboard

Cybersecurity icons and illustrations

Beginner-friendly language

Main Sections

1. Landing Page

Hero banner

"Think Before You Click"

Brief introduction to cybersecurity

Start Training button

2. Phishing Awareness Simulator

Create a realistic-looking fake login page simulation.

When a user enters credentials:

Do NOT save any data.

Display: "This was a phishing simulation. Never enter credentials on untrusted websites."

Show:

Suspicious URL indicators

Fake urgency messages

Missing HTTPS examples

Include:

Explain why the page is suspicious.

Tips to identify phishing websites.

3. Password Security Lab

Interactive password strength checker.

Show:

Weak

Medium

Strong

Very Strong

Analyze:

Length

Numbers

Uppercase letters

Symbols

Display educational estimates like:

"Could be guessed quickly"

"Much harder to guess"

Include:

Password best practices

Common mistakes

4. URL Inspection Challenge

Display multiple URLs.

Examples:

Legitimate URLs

Look-alike domains

Misspelled domains

Allow users to select whether each URL is safe or suspicious.

Provide explanations after each answer.

5. Two-Factor Authentication Simulator

Visual simulation showing:

Step 1: Password entered

Step 2: OTP requested

Step 3: OTP verified

Step 4: Access granted

Include animations showing how 2FA protects accounts.

6. Social Engineering Demonstration

Interactive scenario where users answer simple questions.

Show how attackers can use:

Birthdays

Pet names

Favorite teams

Public social media information

Explain why oversharing can be risky.

7. Metadata Privacy Demonstration

Simulate a photo upload.

Display educational metadata such as:

Date taken

Device type

GPS location (simulated)

Explain privacy risks.

No actual metadata extraction is required.

8. Public Wi-Fi Security Demo

Create a simulation with networks:

Airport_Free_WiFi

Airport Official WiFi

Cafe Guest Network

Ask users which one they would choose.

Explain risks of rogue hotspots.

9. Cybersecurity Quiz

20 questions.

Topics:

Phishing

Passwords

Social engineering

Safe browsing

Mobile security

2FA
